## Türkçe

Bu hafta siber güvenlik dünyasında öne çıkan en kritik gelişmeler ve teknik detayları:

### 1. [FBI, Küresel Siber Saldırıları Otomatikleştiren ARTEX AI Aracına Karşı Uyarıyor](https://www.bleepingcomputer.com/news/security/fbi-warns-artex-ai-hacking-tool-is-powering-global-cyberattacks/)
**Kategori:** `AI / Cyberattack` | **Kaynak:** `BleepingComputer`

FBI, siber saldırganların küresel çapta otomatize siber saldırılar düzenlemek için ARTEX adında yapay zekâ destekli bir sızma testi altyapısı kullandığı uyarısında bulundu. Söz konusu aracın, yakın zamandaki bir ConnectWise tedarik zinciri ihlali üzerinden Microsoft 365 müşteri ortamlarını kompromize etmek için kullanıldığı bildirildi.

### 2. [Cursor, Güvenlik İhlalinin Zararlı Claude Code Eklentisine Yol Açtığını Doğruladı](https://www.bleepingcomputer.com/news/security/cursor-confirms-security-breach-led-to-malicious-claude-code-extension/)
**Kategori:** `Supply Chain Attack` | **Kaynak:** `BleepingComputer`

Cursor, AI altyapı sağlayıcısı Fireworks AI'dan çalınan yetkili erişim bilgileri vasıtasıyla kendi eklenti pazarında kötü amaçlı bir Claude Code eklentisinin dağıtıldığını ve bir güvenlik ihlali yaşandığını doğruladı. Olay, AI geliştirme araçlarına yönelik tedarik zinciri saldırısı risklerinin arttığını bir kez daha gösteriyor.

### 3. [Microsoft 1.100'e Yakın Güvenlik Zafiyeti İçin Yama Yayınladı](https://krebsonsecurity.com/2026/11/microsoft-fixes-nearly-1100-security-vulnerabilities/)
**Kategori:** `Vulnerability / Zero-Day` | **Kaynak:** `Krebs on Security`

Microsoft, Windows işletim sistemleri ve desteklenen yazılımlarındaki 63'ü kritik seviyede olan 1.100'e yakın güvenlik zafiyetini kapatan devasa bir güncelleme paketi yayınladı. Yamalar arasında Microsoft Outlook üzerinde tespit edilen ve aktif olarak istismar edilen bir sıfırıncı gün (zero-day) zafiyeti de yer alıyor.

## English

The most critical cybersecurity developments and technical insights of the week:

### 1. [FBI warns ARTEX AI hacking tool is powering global cyberattacks](https://www.bleepingcomputer.com/news/security/fbi-warns-artex-ai-hacking-tool-is-powering-global-cyberattacks/)
**Category:** `AI / Cyberattack` | **Source:** `BleepingComputer`

The FBI warned that threat actors are leveraging an AI-powered penetration testing framework called ARTEX to automate cyberattacks against organizations globally. The framework has been linked to a ConnectWise supply-chain compromise affecting Microsoft 365 customer environments.

### 2. [Cursor confirms security breach led to malicious Claude Code extension](https://www.bleepingcomputer.com/news/security/cursor-confirms-security-breach-led-to-malicious-claude-code-extension/)
**Category:** `Supply Chain Attack` | **Source:** `BleepingComputer`

Cursor confirmed a security breach after attackers stole credentials from AI infrastructure provider Fireworks AI to distribute a malicious Claude Code extension through its marketplace. The incident highlights emerging supply-chain exposure in developer-focused AI tool ecosystems.

### 3. [Microsoft Fixes Nearly 1,100 Security Vulnerabilities](https://krebsonsecurity.com/2026/11/microsoft-fixes-nearly-1100-security-vulnerabilities/)
**Category:** `Vulnerability / Zero-Day` | **Source:** `Krebs on Security`

Microsoft released a massive Patch Tuesday update resolving nearly 1,100 vulnerabilities across its Windows operating systems and software ecosystem. The release includes fixes for 63 critical flaws, featuring an actively exploited zero-day vulnerability in Microsoft Outlook.
